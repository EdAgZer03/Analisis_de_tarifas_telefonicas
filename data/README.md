# Datos de entrada

El proyecto utiliza cinco archivos del ejercicio de Megaline de TripleTen:

| Archivo | Contenido |
|---|---|
| `megaline_plans.csv` | Tarifas, límites incluidos y costos por excedente. |
| `megaline_users.csv` | Usuario, plan, región y fechas de registro o baja. |
| `megaline_calls.csv` | Fecha y duración de cada llamada. |
| `megaline_messages.csv` | Fecha de cada mensaje. |
| `megaline_internet.csv` | Fecha y MB consumidos por sesión. |

Obtén los archivos desde el material del curso al que tengas acceso. Colócalos en esta carpeta o configura `MEGALINE_DATA_DIR` con su ubicación. Los datos no se incluyen en el repositorio. Los nombres de las personas no se utilizan en el análisis ni se muestran en sus tablas.
